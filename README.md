# one's studio

一个本地优先的体脂/训练/饮食记录 PWA。绝区零（ZZZ）风格：墨黑终端底、荧光青柠只做点缀、警戒带与等宽 `//` 标签。

**只用于记录、健康管理与改善生活习惯，不提供诊断、治疗、处方或疗效承诺。**

## 运行

纯静态、无构建步骤、无框架、无后端。

```bash
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

开发/测试：

```bash
npm install
npm test        # vitest，逻辑层红绿测试
```

## iPhone 安装（推荐）

1. 部署到 GitHub Pages 或 Cloudflare Pages（静态托管，0 元）。
2. iPhone Safari 打开网址 → 分享 → **添加到主屏幕**。
3. 从主屏幕图标打开，独立全屏 Web App，无浏览器栏。

> **务必定期导出备份。** iOS 会在长期无交互后清理脚本可写存储（主屏 Web App 有独立计数器，但仍可能触发）。「计划」页 → 导出备份 → 存到「文件」App。换机时用「导入备份」恢复。

## 数据

- 全部数据在本机 `localStorage`，不上传。日志按月分片 `os:logs:YYYY-MM`。
- 一键导出 JSON（`backupVersion=1`）；导入支持覆盖 / 合并（合并时本机优先），事务式写入，失败回滚。
- `api_key`、`base_url`、`model` **不会进入导出文件**。
- 内部迁移链 `schemaVersion 0→1→2→3`，禁跳级。
- 04:00 日切，读时结算，无后台定时器。

## 一期功能

| 页面 | 内容 |
|---|---|
| 首页 HOME | 双环（外=本周进度 / 内=今日完成度）、顶部倒计时小字、宏量缺口。进度**全自动推导**，首页不再有待办清单、不再有工具条 |
| 记餐 FOOD | 42 项高频食物库、检索、三餐累加、已摄入与剩余、「生成今日吃法」入口 |
| 生成吃法 EAT | **内置算法**按已摄入与剩余缺口从食物库组合 2-3 组候选（无需配置、不发请求）；昨天吃过的今天不再推荐；每条可「换」；配置 AI 后可另选 AI 生成 |
| 打卡 TASK | 按**肌群 × 锻炼条件**（健身房 / 居家哑铃 / 徒手无器材）生成可替换候选，选好点「完成」即记录；锁定后仍可随时换 |
| 训练 GYM | 当日模板、组次打卡、连续 2 次达上限建议 +2.5kg（动作模板随计划可自定义） |
| 称重 WT | 体重记录、周均趋势 |
| 历史 | GitHub 贡献方块风热力图，每天完成度越浅越少（也内嵌在「我的」的左侧弹出层里） |
| 我的 ME | 头像（可换）+ 名称、个人信息细项（名称/出生日期/身高/性别，均为**左侧弹出层**编辑）、历史/计划/AI 入口、备份、浅色/深色主题 |
| 计划 | 多计划新建/复制/编辑/切换/删除、导出导入 |
| 计划编辑 | 期限、宏量、食物、**训练模板（四个分化的动作可增删改名称/组数/次数/重量）**、自身与期望指标 |
| AI 设置 | `base_url`/`api_key`/`model` 三字段，填齐即启用；密钥只存本机、不回显明文、不进导出备份 |

「生成今日吃法」二期已开放：请求只在用户点击时发出（OpenAI 兼容 `/v1/chat/completions`），无后台请求。

食物与运动的推荐**全部是固定规则代码，不调用 AI**：食物按场景池 + 昨日排除 + 缺口偏移；运动按肌群 × 锻炼条件池 + 本周已练排除。AI 只作为「生成吃法」里的可选增强。

## 字体

标题与数字用系统窄体栈 `Impact → Arial Narrow → DIN Condensed`，中文一律系统黑体、常规字重、不斜体。

一期**不随包附带字体二进制，也不声明 `@font-face`**，因此运行时零字体请求、完全离线可用。原因：仓库没有 Anton 源文件，且 Impact / Arial Narrow 是系统商业字体，不允许打包再分发；先前指向 `assets/fonts/anton-subset.woff2` 的声明会产生 404，绝对路径在 GitHub Pages 子路径下也会失败，已移除。

若要精确还原 Anton 窄体标题，按 `docs/visual-tokens.md` §4 的 `pyftsubset` 命令自行生成 ≤15KB 子集放入 `assets/fonts/`，再在 `src/styles/base.css` 用**相对路径** `../assets/fonts/anton-subset.woff2` 加回 `@font-face`，并把 `base.css` 加进 `sw.js` 预缓存（现已在清单中）。

## 交互自检

`npm test` 只覆盖逻辑层。浏览器里还有一项真实点击自检，用来挡住 `element.click()` 测不出来的问题（例如某层 `pointer-events: none` 被整棵子树继承，导致页面看着正常、实际全站点不动）：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
# 打开 http://127.0.0.1:8765/tests/hit-test.html
```

页面逐项输出 PASS/FAIL：可点元素是否被误设为 `pointer-events: none`、鼠标中心点 `elementFromPoint` 是否命中目标、真实 bubble click 能否触发打卡确认。改过 CSS 后建议跑一次。

另有三个端到端探针，同一个静态服务下直接打开即可（每个都用干净的浏览器 profile 跑，避免残留 localStorage 干扰）：

- `tests/custom-training-probe.html`：计划编辑改名/新增动作 → 保存 → 训练页生效、环心文案、宏量卡跳记餐、打卡页去重。
- `tests/home-eat-probe.html`：首页双环与无待办、打卡候选可换/确认后可换/锻炼条件切换、昨日排除、历史热力图、内置生成吃法可换、AI 生成请求体。
- `tests/settings-probe.html`：个人信息细项左侧弹出层（名称/身高/性别）、历史左弹层、主题切换、无计划名文案、首页无待办。

## 一期已知偏差（二期处理）

发布前独立代码评审判定无 Critical，以下为已记录的 Minor / 观察项，不影响当前功能：

- 提示形态：错误与说明目前走 3.2s 自动消失的 toast；`docs/interaction-spec.md` §3.2 要求错误不用 toast、L2 提示常驻。
- 迁移链：`migrate` 生成 `steps=[1,2,3]` 但一次写入版本号；一期无字段差异，未来引入字段转换前需补逐级迁移函数。
- 危险按钮：`.btn-para--warn` 在 `components.css` / `app.css` 各有一份，靠加载顺序由后者覆盖，表现正确但需收敛。
