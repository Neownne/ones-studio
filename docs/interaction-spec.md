- 6 tab 固定语义 + 文字标签，不靠图形猜。

## 1. 动效规范

### 1.1 总规则

- 统一时长 **140ms**。任何状态过渡不得超过 140ms；按下即时反馈必须在 ≤140ms 内出现第一帧变化——用 `:active` / `touchstart` 直接触发，**不得等 JS 计时器**（避免绝区零被批评的 1s 延迟）。
- **允许的动效属性（白名单，仅此四类）**：

  | 属性 | 允许范围 |
  |---|---|
  | `transform: translate(x, y)` | 仅 1px 量级；**禁止** scale / rotate |
  | `box-shadow` 的 offset | 硬偏移收拢（如 6px→2px）；**blur 恒为 0**，颜色不变（黑 .55 或青柠 .55） |
  | `background-color` | 仅在 12 个 token 内切换 |
  | `border-color` / `color` | 仅在 12 个 token 内切换 |

- **禁止**：`scale`、`rotate`、`opacity` 过渡、`filter`、`blur`、`backdrop-filter`、全屏闪烁、循环 `@keyframes`（唯一例外：启动页扫描线）。
- 缓动：按下/收拢用 `ease-out`（立即响应、快速到位）；恢复原状用 `ease-in-out`。不用弹性/回弹（不符合「硬」的质感）。
- 参考声明：
  ```css
  transition: transform .14s ease-out, box-shadow .14s ease-out,
              background-color .14s linear, border-color .14s linear, color .14s linear;
  ```

### 1.2 `prefers-reduced-motion` 降级

- 必须：在 `@media (prefers-reduced-motion: reduce)` 下**关闭所有位移与硬偏移收拢动效**——`transition: none; animation: none;`。
- 降级后按下反馈**只保留颜色瞬时切换**（无位移、无阴影收拢）；tab 选中斜切块滑动改为瞬时出现；启动页扫描线关闭。
- 判定：开启系统「减少动态效果」后，全 App 无任何移动/滑动/收拢动画，但功能与按下颜色反馈仍完整。

## 2. 按下反馈规范（五类，ZZZ 反馈语言 = 硬偏移收拢 / 颜色反转 / 1px 位移）

> 统一原则：用「**硬偏移收拢 + 1px 位移**」做物理按压感，用「**颜色反转**」做状态确认。**按下 ≠ 选中**：按下是瞬时反馈（≤140ms，松开恢复），选中是持续状态（见 §6 tab 与 chip）。**禁止用 scale 缩放做反馈**（ZZZ 不用缩放，用位移与偏移收拢）。
> 位移方向统一：元素向阴影偏移方向移动 1px，同时阴影收拢（例：默认 `box-shadow: 6px 6px 0 …`，按下 `transform: translate(1px,1px)` + 阴影变 `2px 2px 0 …`），形成「按下去」的物理感。

### 2.1 主按钮（青柠 CTA）

- 默认：`accent #d8fa00` 底 + 深文字 `canvas #0a0a0a` + 平行四边形 `skewX(-24°)` 形态 + 硬偏移 `box-shadow: 6px 6px 0 rgba(216,250,0,.55)`（青柠偏移）。
- 按下：硬偏移收拢 `6px→2px` + `translate(1px,1px)` + **颜色反转**为 `canvas` 深底 + `accent` 文字 + `1px accent` 描边。松开恢复默认。
- 判定：按下瞬间可见「色块按下去」（阴影收拢 + 元素位移）且反色；140ms 内完成；不缩放。

### 2.2 危险按钮（amber，不可逆操作：删除计划 / 清空 api_key / 覆盖导入）——组件 `danger-btn`

- 默认：`panel-0` 底 + `1px amber` 描边 + 左侧 24px **危险斜纹竖带**（见 §4）+ amber 明确动词文字 + 硬偏移 `6px 6px 0 rgba(0,0,0,.55)`（黑偏移）。
- 按下：硬偏移收拢 `6px→2px` + `translate(1px,1px)` + 危险斜纹带反色（amber 与 panel-2 交替的色相对调，方向不变）+ 文字保持 amber。**禁止**整钮变红；**禁止**整钮 amber 填充成「主按钮」（会丢失危险语义、与主按钮混淆）。
- 判定：按下有收拢 + 位移 + 斜纹反色；仍是 panel 底 + amber 斜纹 + amber 明确动词，一眼识别「危险」而非「主行动」。

### 2.3 chip（可点标签，如图例 chip、筛选 chip）

- 默认：`panel-1` 底 + `1px line` 描边 + 等宽标签文字 `text-2` + 硬偏移 `3px 3px 0 rgba(0,0,0,.55)`。
- 按下：硬偏移收拢 `3px→1px` + `translate(1px,1px)` + 描边瞬时变 `accent`。**禁止切成「选中态」**（选中态 = accent 底常驻，是另一种持续状态，由逻辑单独控制、与按下解耦；按下只是瞬时，松开回到默认）。
- 判定：按下只是「轻按」（收拢 + 位移 + 描边亮），不变 accent 底；不会被误当成已选中。

### 2.4 底部 tab（6 个）

- 按下：该 tab 文字 `translate(1px,1px)` + 文字立即 `text-1` 高亮（≤140ms）；**不做**整格反色块、不缩放。
- 切换：选中的青柠斜切块下划线（见 §6.2）从原 tab **`translateX` 140ms 滑动**到新 tab，文字颜色 `text-3→accent` 140ms 渐变。
- 判定：按下有即时高亮 + 1px 位移；切换时下划线平滑滑动 140ms；整 tab 不反色、不缩放。

### 2.5 可点卡片（计划卡片 `plan-card`、食物条目卡等）

- 默认：`panel-0` 底 + `1px line` 描边 + 斜切角（右上/左下 `clip-path`）+ 硬偏移 `6px 6px 0 rgba(0,0,0,.55)`。
- 按下：硬偏移收拢 `6px→2px` + `translate(1px,1px)` + 描边瞬时变 `accent`。松开恢复。
- 判定：卡片按下有明确「按下去」（阴影收拢 + 位移）；描边瞬时 accent 提示可点；不缩放、不透明度变化。

### 2.6 真禁用控件（对照：无反馈）——组件 `ctrl-disabled`

- 真禁用（见 §5.3）：**无任何按下反馈**（无位移、无收拢、无颜色变化），全部元素 `text-4`，不可聚焦、不可点击。与「未启用入口」（有收拢 + 位移反馈但不变 accent，见 §5.2）严格区分。

### 2.7 焦点环（键盘 / 辅助技术）

- 焦点环 = `outline: 1.5px solid accent` + `outline-offset: 2px`（`accent` 用途含「焦点环」，见 DESIGN.md §4.1）。在深色底上 accent 对 canvas/panel 对比足够可见。
- **不用 `box-shadow` 模拟焦点环**（避免与「硬偏移阴影」混淆）；不与按下态/选中态混用；圆角随元素（本设计几乎无正圆角，随切角）。
- 判定：键盘/辅助技术聚焦时有清晰可见的 accent 描边环，且不被误认为按下或选中。

## 3. 提示分级规范（ZZZ 深色终端：首页 L1 标签块 / 二级页 L2 卡片）——组件 `hint`

> 分级**按页面位置，不按错误类型**。装饰层永不压数字与可点区。`hint` 是「终端式标签块」：首页用 L1 轻量形态、二级页用 L2 卡片形态。

### 3.1 首页 L1 标签块（轻量、叠加提示）

- 用途：首页 `home` 的任何叠加提示——口径提示（04:00 结算）、容量 80% 预警、计划已结束/未开始、非关键补充。
- 样式：`panel-1` 底 + `1px line` 描边 + 左侧 3px 竖条 + 等宽 `// ` 前缀小标题（Cascadia Mono 全大写、字距 .12em）+ 正文 `text-2` 13px 常规。高度紧凑（≤56px），只含文字。
- 常规提示：左侧竖条与 `//` 小标题用 `accent`。
- 警告/错误类（容量 95%、写入失败若回落首页）：同样用 L1 标签块，但左侧竖条与 `//` 小标题改 **`amber`**；**不用** L2 卡片（首页不放白底卡片，保持深色终端 + 青柠 ≤5%）。
- 动作按钮：需要动作时**放在标签块下方的 canvas 上**，不嵌进块内（避免撑高超 56px）。
- 判定：首页出现的提示都是 panel-1 + 左侧竖条（accent 常规 / amber 警告）+ `//` 标签，紧凑、不压数字、青柠 ≤5%。

### 3.2 二级页 L2 提示卡（明确、可常驻）

- 用途：计划列表 `plan-list` / 计划编辑 `plan-edit` / AI 设置 `ai-settings` 等二级页的页面级错误（导入失败、写入失败、容量 95% 拦截、表单确认）。
- 样式：`panel-0` 底 + `1px line` 描边 + 斜切角（右上/左下）+ 硬偏移 `6px 6px 0 rgba(0,0,0,.55)` + 等宽 `// ` 前缀标题（`text-1`；错误/警告改 `amber`）+ 正文 `text-2` 13px 常规 + 动作按钮组。错误/警告卡左侧加 **amber 危险斜纹竖带**（见 §4）。
- 常驻：错误**不用 toast**，用 L2 卡片常驻直到用户处理；可关闭的给「关闭」动作。
- 判定：二级页错误是 panel-0 斜切卡片 + `//` 标题 +（警告时）amber 斜纹竖带，常驻、可判读、不压数字。

### 3.3 分级判定表

| 场景 | 位置 | 级别 | 样式 |
|---|---|---|---|
| 口径提示 / 结算说明 | 首页 | L1 标签块 | accent 竖条 + `//` 标签 |
| 容量 80% 预警 | 首页 / 二级页 | 首页 L1（amber 竖条）/ 二级页 L2 | 按页面位置 |
| 容量 95% 拦截 | 首页 / 二级页 | 首页 L1（amber 竖条）+ canvas 上按钮 / 二级页 L2 卡片 | 按页面位置 |
| 导入 / 写入失败 | 通常在计划列表 | L2 卡片 | amber 标题 + amber 斜纹竖带 |
| 空态导入失败（回落首页） | 首页 | L1 标签块 | amber 竖条 |
| 表单内联错误 | 各页输入区 | 内联 | 输入框 1px amber 描边 + 下方 amber 11px 提示 |
| 宏量超额 | 首页/记餐 宏量卡 | macro-cards amber 态 | amber 文字/描边（可配 amber 斜纹），**不用红**、不进 toast |

> 关键：**导入/导出失败通常发生在计划列表「数据」组**（首页不放入口，仅 0 计划空态有「导入备份 JSON」），那一次是 L2 卡片；只有空态点导入失败回落首页时才用首页 L1。**不要把所有「导入失败」硬编码成 L1。**

## 4. 警戒带斜纹 vs 危险斜纹：区分规则（修订「斜纹唯一归危险」）

> ZZZ 引入「警戒带」作为品牌装饰（`DESIGN.md` §4.4），与「危险斜纹（操作警告）」并存。旧裁定「斜纹全站唯一归属危险操作」**修订为：斜纹分两类，按色相 / 疏密 / 位置 / 方向四维度区分，禁止混用。**

### 4.1 两类定义

| 维度 | 警戒带（品牌装饰） | 危险斜纹（操作警告语义） |
|---|---|---|
| 语义 | 纯装饰、无操作含义 | 不可逆 / 警告操作的语义标记 |
| 配色（色相） | `amber #ffde00` × `canvas #0a0a0a`（高对比品牌黄黑） | `amber #ffde00` × `panel-2 #23251f`（amber 在深灰上，对比更沉；不用纯黑以区别警戒带） |
| 节距（疏密） | **11px**（疏，DESIGN.md §4.4） | **≤5px**（密，更紧张） |
| 方向 | `45°`（/） | `-45°`（\，反向） |
| 形态 / 位置 | 整宽横向细条（高 10–12px），位于**页面顶部分隔、空态容器边缘、加载占位**；永不出现在可操作控件上 | 局部竖向窄带（宽 24px），位于**危险按钮 / 警告卡左侧**；永不做整宽页面装饰 |
| 文字配合 | 无文字（纯装饰） | 必配 amber 明确动词 / 警告文案 |

### 4.2 强制规则

- 警戒带**永不压数字与可点区**（§4.6-4），只做边缘/背景装饰；面积克制（amber 装饰面积也要控制，不喧宾夺主、不与 accent 争强调）。
- 危险斜纹**只出现在危险按钮（§2.2）与警告提示卡（§3.2）的左侧竖带**；整宽装饰一律用警戒带，**禁止把危险斜纹拉满整宽**。
- 同一屏幕同时出现时，两类斜纹在**色相 / 疏密 / 位置 / 方向**四个维度至少三个不同（本设计四个全不同），用户不会把「页面顶部警戒带」误读为「这里有危险操作」。
- **禁止**把警戒带用在危险按钮上（会让危险操作看起来像装饰、弱化警告）；**禁止**把危险斜纹用在整宽装饰上（会让整个页面看起来都是危险操作）。

### 4.3 判定（验收）

- 任取一处斜纹，能立刻归类：整宽横条 + 黄黑 + 11px + 45° + 无文字 → 警戒带（装饰）；24px 左侧竖带 + amber×panel-2 + ≤5px + (-45°) + amber 文案 → 危险斜纹（警告）。**归类不了，或两者特征混搭 → 判不通过。**

## 5. 三态表达（空态 / 未启用入口 / 真禁用控件）

### 5.1 空态（0 计划）——组件 `empty-state`

- 布局：`canvas` 深底，顶部与底部各一条**警戒带**（11px 黄黑，品牌装饰，§4.1）作框定，内容垂直居中。**不渲染双环、四小环、7 项明细**，**禁止画空底环**（空轨道在低对比下会退化成噪点）。
- 元素：等宽 `// NO PLAN` 标签（accent）+ 标题「还没有计划」（`text-1`，系统黑体 24px/700，标题可粗）+ 说明「先建一个，双环和今日额度才有依据。」（`text-2` 13px，≤2 行）+ 主按钮「＋ 新建计划」（§2.1）+ 次按钮「导入备份 JSON」（panel 底 + 1px line 描边 + text-1）。
- 可选：除夕倒计时（Anton 大数字 accent）直接落 canvas，上方 `// ` 等宽小标签 `DAYS TO CNY`、下方「天」，不设环不设卡。
- 数据口径（冻结，对齐 DESIGN.md §5 / PLAN 1.3）：no-plan 日志按 7 项结构存（分母恒 7 是存档口径），`planId=null`，建计划后不回填；第 6 项 `training_or_rest` 为 false 且不可勾；记餐页 `log-meal` 同样隐藏四小环（`computeMacroRemain` 返回 hidden）、只累计摄入数值、不做超额判定（无上限可比），顶部 L1 标签块「未设计划 · 记录仅本地暂存」。
- 判定：空态无白卡、无空环、无双环/四小环；有警戒带框定 + `// NO PLAN` + 两个按钮；青柠只给主按钮与（可选）倒计时数字，整屏 ≤5%。

### 5.2 未启用入口（「生成今日吃法」，在记餐页 `log-meal` 顶部）——组件 `entry-unenabled`

- 样式：`panel-1` 底 + `1px line` 描边 + 斜切角 + 等宽 `// AI` 标签（text-3）+ 正文 `text-3` 13px「生成今日吃法」+ 右侧「未启用」徽章（`panel-2` 底 + `1px line` 描边 + 等宽 `// OFF` 文字 text-3）。**不用 accent**（它不是可执行主行动）、**不用 amber**（未启用不是警告）。
- 按下反馈：硬偏移收拢 + `translate(1px,1px)`（与卡片一致），**不变 accent 色**。
- 点击行为：**绝不发请求**，只弹说明卡（L2）：「AI 助手一期只保存接口设置，还不会生成内容。可以先去 AI 设置填好地址和 key，等下一期开放。」按钮「去设置」「知道了」。
- 判定：未启用入口是 text-3 灰调 + `// OFF` 徽章，可点、有收拢位移反馈、不变 accent；点击只弹说明卡、零网络请求。

### 5.3 真禁用控件（AI 开关，在 AI 设置页 `ai-settings`）——组件 `ctrl-disabled`

- 样式：全部元素用 `text-4 rgba(242,242,238,.24)`（禁用色）——开关轨道 `panel-2` + `line` 描边、滑块 text-4、标签 text-4。恒为关闭。本页为黑底反色页（DESIGN.md §3），真禁用在此页仍以 text-4 呈现。
- 反馈：**无任何按下反馈**（无位移、无收拢、无颜色变化）、不可聚焦、不可点击。点击（若发生）只把焦点移到旁侧说明「一期只保存设置，暂不调用」（text-3），不切状态。
- 与未启用入口严格区分：真禁用 = text-4 + 无反馈 + 无响应；未启用入口 = text-3 + 有收拢位移反馈 + 可点弹说明。**两者不得共用样式。**
- 判定：`enabled` 恒 false；任何路径下开关不变开启态；全局零网络请求。

## 6. 底部 6 tab 交互——组件 `tab-bar`

### 6.1 结构与标签（固定语义，不靠图形猜）

- tabbar = `panel-0 #141614` 底 + 顶部 `1px line` 描边分隔；6 等分，每格整格可点。
- 每格 = **等宽全大写英文文字标签**（必须）：`HOME / FOOD / TASK / GYM / WT / LIST`，Cascadia Mono、全大写、字距 **.12em**（取下限省宽度；**不带 `// ` 前缀**，53px 格宽放不下前缀）。可选辅助小编号 `01–06`（等宽、text-3），不喧宾夺主、可选；**禁止只有图标/编号、无文字标签**。
- 字号：标签 10px 等宽；320px 屏每格 53px 宽内完整显示最长 4 字符（HOME/FOOD/TASK/LIST），不截断、不换行。
- 热区：每格整格 ≥44×44px（tabbar 高 ≥48px）；斜切角/斜切块不影响可点区（用 `::after` 扩热区）。

### 6.2 选中态（青柠斜切块 + 文字标签）

- 选中 tab = 文字 **`accent #d8fa00`**（accent 用途含「选中 tab」，DESIGN.md §4.1）+ 文字下方**青柠斜切块下划线**（宽≈文字宽、高 3px、`skewX(-24°)` 平行四边形、accent；与 DESIGN.md §4.4「斜切小色块做下划线/强调」同源）。
- 未选中 = 文字 `text-3`、无下划线。
- 判定：当前 tab 一眼可辨（accent 文字 + 青柠斜切块下划线）；青柠仅出现在选中那一格，整屏 accent ≤5%。

### 6.3 按下与切换反馈

- 按下：该 tab 文字 `translate(1px,1px)` + 立即 `text-1` 高亮（≤140ms）；不整格反色、不缩放。
- 切换：选中下划线 `translateX` **140ms** 从原 tab 滑到新 tab；文字颜色 `text-3→accent` 140ms 渐变；页面随 hash 路由**瞬时切换**（不做整页 opacity 过渡；可选页面内容 1px 向上位移进入，reduced-motion 关闭）。
- 判定：按下即时高亮 + 1px 位移；切换下划线平滑滑动 140ms；整 tab 无反色块、无缩放。

## 7. 可用性验收清单（code review 逐条勾选，每条可判定 通过 / 失败）

> 方法：iPhone 真机（主屏 Web App）+ 截图对照 `DESIGN.md` §4 与本规范。任何一条不满足即不通过。逻辑边界以 `npm test` 全绿为准（见 PLAN Phase 1/2），本清单覆盖视觉与交互。

### A. 色板与层级（对应 §4.6-1、§4.1 纪律）

- [ ] 画布用 `#0a0a0a`，**无 `#000` 纯黑**；文字为四档白（text-1/2/3/4），**无纯白 `#fff` 大字**。
- [ ] 青柠 `accent` 整屏面积 ≤5%（只给主行动/选中 tab/进度弧/焦点环/编号徽章），无大面积铺底、无渐变铺底。
- [ ] **无红色功能色**；错误/危险/超额用 `amber` + 斜纹 + 文案。
- [ ] 层级只靠底色阶差（canvas/panel-0/1/2）+ `1px line` 描边 + 硬偏移（3/6/8px、0 blur）；**无软阴影、无发光、无模糊**。
- [ ] `amber` 只用于警告语义（超额/预警/危险），未用于常规交互强调（主按钮/选中/进度弧是 accent 不是 amber）。
- [ ] 文本四档（text-1/2/3/4）对比降台阶，无纯黑配纯白。

### B. 字体（对应 §4.6-2、§4.2）

- [ ] 标题/数字用 Anton（或回退窄体），**无合成加粗**（Anton 上不叠加 `font-weight:bold`）。
- [ ] 正文系统黑体 14px/400，**常规字重、不斜体**；粗体只出现在标题与数字。
- [ ] 等宽标签 Cascadia Mono、全大写、字距 .12–.38em、页面内带 `// ` 前缀；数字优先 tabular/Impact。
- [ ] 中文正文无「伪造品牌感」（无斜体、无全大写中文、无特效字）。

### C. 6 tab（对应 §4.6-3、§6）

- [ ] 6 tab 为 `HOME/FOOD/TASK/GYM/WT/LIST` 等宽大写英文文字标签，**每格都有文字、不靠图形猜**。
- [ ] 320px 屏每格 53px 内最长 4 字符完整显示、不截断、不换行。
- [ ] 选中 tab = accent 文字 + 青柠斜切块下划线（`skewX(-24°)`）；未选中 = text-3、无下划线。
- [ ] 热区每格 ≥44×44px、tabbar 高 ≥48px；切角不影响可点（`::after` 扩热区）。
- [ ] 按下即时高亮 + 1px 位移（≤140ms）；切换下划线 140ms 滑动、文字渐变；整 tab 无反色块、无缩放。

### D. 动效与按下反馈（§1、§2，对应 §4.5）

- [ ] 全 App 过渡统一 **140ms**；按下反馈 ≤140ms 内出现（`:active`/`touchstart` 直接触发，无 JS 延时）。
- [ ] 动效属性仅 `translate(≤1px)` + `box-shadow offset(blur=0)` + 颜色；**无 scale、无 rotate、无 opacity 过渡、无 filter/blur/backdrop-filter、无全屏闪烁**。
- [ ] 主按钮按下 = 偏移 6→2px + 1px 位移 + 反色（深底 accent 字）；危险按钮 = 偏移收拢 + 1px 位移 + 斜纹反色（不整钮变红、不整钮 amber 填充）；chip = 收拢 + 位移 + 描边亮（不变 accent 底）；卡片 = 收拢 + 位移 + 描边亮。
- [ ] 无循环 `@keyframes`（启动页扫描线除外）。
- [ ] 焦点环为 1.5px accent outline + 2px offset（不用 box-shadow），深色底可见，不与按下/选中混淆。
- [ ] 开启 `prefers-reduced-motion` 后无位移/收拢/滑动动画，仅保留按下颜色反馈，功能正常。

### E. 提示分级（§3）

- [ ] 首页叠加提示为 L1 标签块：panel-1 + 1px line + 左侧 3px 竖条（常规 accent / 警告 amber）+ `//` 标签 + text-2，紧凑 ≤56px，按钮在块外 canvas 上。
- [ ] 二级页错误/预警为 L2 卡片：panel-0 + 1px line + 斜切角 + 硬偏移 + `//` 标题（错误 amber）+（警告）amber 斜纹竖带，常驻不用 toast。
- [ ] 分级**按页面位置**：导入/写入失败在计划列表是 L2 卡片，空态回落首页才是 L1；首页不出现 L2 白底卡片。
- [ ] 错误不用 toast、不用彩色、不用插画；`text-3` 不单独承载唯一错误信息（错误有 amber/标题/竖条等明确层级）。
- [ ] 宏量超额为 macro-cards amber 态（amber 文字/描边，可配 amber 斜纹），不用红、不进 toast。

### F. 警戒带 vs 危险斜纹（§4）

- [ ] 页面顶部/空态/加载的整宽横条 = 警戒带（amber×canvas、11px、45°、细条、无文字），**未压数字与可点区**。
- [ ] 危险按钮/警告卡左侧竖带 = 危险斜纹（amber×panel-2、≤5px、-45°、24px、配 amber 文案）。
- [ ] 两类斜纹同屏时在色相/疏密/位置/方向至少三个维度不同；无「警戒带当危险用」或「危险斜纹整宽铺」。
- [ ] 危险按钮仍是 panel 底 + amber 斜纹 + amber 明确动词，一眼识别「危险」而非「主行动」。

### G. 三态（§5）

- [ ] 空态：无白卡、无空底环、无双环/四小环；canvas + 顶部/底部警戒带 + `// NO PLAN` + 标题 + 说明 + 主/次按钮；青柠 ≤5%。
- [ ] 未启用入口（记餐页「生成今日吃法」）：text-3 灰调 + `// OFF` 徽章，可点、按下有收拢位移、不变 accent；点击只弹说明卡、**零网络请求**。
- [ ] 真禁用（AI 开关）：全 text-4、无任何反馈、恒关闭、`enabled=false`；与未启用入口样式不混。
- [ ] AI 一期全局零网络请求（AI 设置保存、点「生成今日吃法」、拨动开关后，无任何对外请求）。

### H. 装饰层与可读性（对应 §4.6-4、§10）

- [ ] 网点/警戒带/斜切色块/扫描线等装饰层**永不压住数字与可点区**（双环数字、宏量数字、倒计时、按钮均可读可点）。
- [ ] 双环/倒计时/宏量缺口随数据实时刷新；双环底环 `line`、完成弧 `accent`、轮廓清晰，装饰不压弧与数字。
- [ ] 扫描线只出现在启动页。
- [ ] iPhone 真机首屏 <800ms；点击反馈 ≤140ms。
- [ ] 合规：只做记录/健康管理，无诊断/治疗/疗效文案。
